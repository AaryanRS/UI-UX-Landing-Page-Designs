---
---

##  `Inside Each Design Folder` 📖
Every design folder contains:
- **Preview Image** → quick look at the design  
- **README.md** → explanation + usage notes  
- **Prompt** → the AI/UI/UX prompt used for generation  
- **HTML Code** → the actual frontend code  

---

## `How to Run` 🚀
1. Clone the repo  
2. Open the design folder in **VS Code**  
3. Install the **Live Server extension**  
4. Right‑click the HTML file → *Open with Live Server*  
5. Enjoy the design in your browser 🎉
